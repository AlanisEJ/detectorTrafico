# Registros originales

Estos tres archivos son evidencia del prototipo y se preservan byte por byte. Mezclan formatos y pueden contener múltiples filas de un mismo track. No representan un conteo validado de vehículos únicos.

El programa nuevo nunca escribe aquí ni concatena estos registros al CSV de esquema v1. La normalización histórica debe producir una salida separada, conservar la procedencia y documentar cualquier unión por ID/tiempo.
